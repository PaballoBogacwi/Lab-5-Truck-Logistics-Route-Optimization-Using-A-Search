# Lab-5-Truck-Logistics-Route-Optimization-Using-A-Search
This project implements the A* Search Algorithm to solve a truck logistics route optimization problem in a weighted graph environment. The objective is to determine the most efficient delivery route from the starting location to the destination while minimizing total travel cost using heuristic-guided search.

📌 Features
Implementation of the A* Search Algorithm
Heuristic-based route optimization
Weighted graph pathfinding
Bug fixing and completion of incomplete AI code
Test case validation
Optimal path and total cost calculation
